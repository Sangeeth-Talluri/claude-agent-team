### 1. OpenHarness — HKUDS's lightweight harness with built-in cost tracking
- **Link:** https://github.com/HKUDS/OpenHarness
- **Attention:** 16,233 stars, 2,625 forks, pushed today (2026-11-22). From the HKUDS team behind DeepCode (covered Nov 21).
- **What it does:** A lightweight agent harness (`oh` CLI) with tool-use, skills, memory, and multi-agent coordination, plus `ohmo`, a personal agent built on it that runs on a Claude Code or Codex subscription — no extra API key. 43+ tools, on-demand skill loading from `.md` files, token counting and cost tracking built into the loop, 114 tests passing.
- **Real:** The two features that matter are both things this repo does not have yet: skills load only when needed (every loaded skill is tokens on every turn), and the loop counts tokens and cost as it runs instead of discovering the bill later. The subscription-based `ohmo` model matches exactly how this repo's bots run. MIT licensed, CI green, same serious research group as DeepCode.
- **Hype/missing:** It is another whole harness to adopt, not a drop-in — adopting it would replace this repo's Claude Code-based kits. It overlaps DeepCode from the same authors, so the team's own lineup is fragmenting; pick the lighter one deliberately, not by accident. The 43-tool count is a feature list, not a quality signal.
- **License:** MIT. **Maintenance:** Very active (pushed today).
- **Verdict:** ADOPT (selectively) — lift on-demand skill loading + built-in token/cost tracking into both control planes; do not rebuild on OpenHarness.

### 2. CowAgent — the personal-agent harness with a memory system worth copying
- **Link:** https://github.com/zhayujie/CowAgent
- **Attention:** 48,042 stars, 10,444 forks, pushed today (2026-11-22). Created Aug 2022 — a mature project, not a launch-week spike.
- **What it does:** An open-source personal AI agent and harness: it plans tasks, uses tools/skills/MCP, runs 24/7, and is reachable from web, WeChat, Telegram, Slack and more. Multi-agent teams where each agent has its own role, model, skills, and knowledge in a shared conversation. A Skill Hub for one-click skill installs.
- **Real:** The memory design is the best-documented one seen in this scan series: three tiers (context → daily → core), automatic "Deep Dream" distillation of the day's conversations into lasting memory, and a knowledge graph wiki the agent curates itself. The self-evolution pass — the agent reviews its own conversations, improves its skills, and follows up unfinished tasks — is the same job this repo's Chief of Staff should be doing every night. Per-agent model choice inside one team is the tiered-routing idea (Nov 21) applied by role instead of by task.
- **Hype/missing:** It is a whole product built chat-first (WeChat-heavy) — adopting it would replace the bot-company, not improve it. "Self-evolution" is the author's framing; there is no published measurement of whether the distilled memory actually helps or quietly drifts. The 48k stars are spread over four years, so the daily attention is lower than the total suggests.
- **License:** MIT. **Maintenance:** Very active (pushed today).
- **Verdict:** WATCH the product, ADOPT the patterns — the three-tier memory + nightly self-evolution review belong in the bot-company.

### 6. OpenHuman — REVISIT: the compression mechanism behind the big claim
- **Link:** https://github.com/tinyhumansai/openhuman
- **Attention:** 42,804 stars, 4,229 forks, pushed today (2026-11-22). (Skip-listed Nov 20 as an unverified claim; this is a second look after reading the mechanism.)
- **What it does:** A Rust agent harness and desktop app. Its headline ideas: RLM token compression (built on the Recursive Language Models paper, arXiv:2512.24601) — large tool results get compressed before the model reads them, and very large ones become a searchable handle instead of text; Jev, a tiny model that picks the right tool out of 1,215 (86.8% top-pick accuracy vs 70.5% for keyword search); and a shared Rust runtime so a fleet of agents costs ~8x less memory/CPU. Claims: 2.6x fewer tokens than the typical agent tool, coding tasks in ~20 seconds.
- **Real:** The mechanism is the part worth taking seriously — compress-then-handle is a genuinely different answer to context bloat than yesterday's offload-to-disk rule, and it is paper-backed with a public benchmarks repo. The Jev tool-search number is a real measurement, not a slogan. A Rust library you can call like a function is the right shape for a future fleet.
- **Hype/missing:** Every performance number is self-benchmarked by the authors (their own harness, their own benchmark repo, their own test set) — no independent verification yet. It still labels itself early beta, it is GPL-3.0 (copyleft — that matters if the bot-company ever becomes a product), and the "500 agents on a $10 VPS" headline is a fleet-size claim, not a quality claim. It is a whole harness, not a pattern to install.
- **License:** GPL-3.0. **Maintenance:** Very active (pushed today).
- **Verdict:** WATCH the product, ADOPT the pattern — the compress-then-handle rule for large tool results belongs in the control planes; note the GPL before borrowing any code.
