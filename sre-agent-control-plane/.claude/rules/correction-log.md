# Correction Log
Every time a human corrects an agent, one line lands here the same day.
The gardener reviews it weekly: a correction that appears twice must graduate
into a lint rule, a type, a test, a hook, or an architecture change (Plan 1's
hierarchy) — or it will be re-taught forever.

Format: date — what the agent did — what it should have done — graduation status
