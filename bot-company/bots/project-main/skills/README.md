# Skills for this bot

This bot uses the skills that live in its repo: `<repo>/.claude/skills/`
(verification skill, Feature Map, debug / feature-dev / perf / code-review —
see Plan 1, Phases 2–3). Do not copy skills into this folder; one source of truth,
in the repo, versioned with the code.

Bot-specific skills that are NOT about the repo (e.g. "how to write this bot's daily
summary") may live here as `skills/<name>/SKILL.md`.
